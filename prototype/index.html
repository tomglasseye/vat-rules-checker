    Test scenarios

    Each scenario is a sale with a known correct answer, based on Miranda's answers up to 14 October. They rerun every time a rule or rate changes, so an edit can't quietly break another case. Add more from the checker with “Save as test scenario”.

      Standard VAT rates

      Used by rules set to “delivery country's standard rate” and by the {rate} and {destRate} placeholders. Values match the published 2026 standard rates. Changed values are highlighted.
